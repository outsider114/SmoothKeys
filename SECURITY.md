# Security Policy

Security fixes target the latest release.

Please report security vulnerabilities privately through
[GitHub security advisories](https://github.com/outsider114/SmoothKeys/security/advisories/new).
Do not publish credentials, keyboard identifiers, or unredacted diagnostic logs
in public issues. Include the affected version and reproduction steps.

SmoothKeys stores settings and limited scroll diagnostics locally. It does not
record typed text or send telemetry. Release apps are currently ad-hoc signed
and not notarized; download only from this repository's Releases and verify
the supplied SHA256SUMS.
